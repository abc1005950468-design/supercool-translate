## 当前实现顺序

1. **P0 壳与记录**：底部导航（同传/记录/我的）、首页模式与语言对、记录持久化、重命名/星标/删除/导出。
2. **P0 同传增强**：暂停/恢复、字号、隐藏原文、混排/分屏、分享、结束确认。
3. **P1 质量能力**：TTS、术语表、AI 助手关键词/上下文、AI 纪要、用量统计。
4. **P1 多语言**：语言列表、目标多选、模型/语言对校验。
5. **P2 协作**：演讲分享、二维码、局域网观众、组织工作区。
6. **P3 云端账号**：登录、会员、订单、发票、声音克隆。
