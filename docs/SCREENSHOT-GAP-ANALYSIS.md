## 截图里的六个教程步骤

1. **音频源**：Select Audio Source，可选 Computer Audio / Microphone Audio；教程注明“App 暂不支持电脑声音”。
2. **语言对**：选择源语言/目标语言，点击开始后自动检测发言人语言并显示在对应区域。
3. **语音播报**：Start Playback、Select Voice（如 Deep-voiced）、Volume；需要扬声器输出。
4. **面板控制**：Font Size、Flip、Panel（单/双面板）、Text（仅原文、仅译文、混合、分离）。
5. **会议共享**：Teams/Zoom/Google Meet 共享屏幕时开启“共享声音”。
6. **AI 助手**：知识库、关键词、上下文、个性化；关键词示例 `Biopsy = 活检`。

## 关键差异（容易漏）

1. **语言自动检测 ≠ 说话人区分**：原版“自动检测发言人的语言”是 LID（语言识别），我们目前做的是声纹“发言人 N”，两者不是一回事。
2. **原版 App 自己也不支持电脑声音**：教程明确写“App 暂不支持”；手机端做到麦克风/蓝牙设备选择即可，系统声音是加分项。
3. **AI 助手不是单纯文本框**：有知识库开关、手动/自动关键词、AI 学习、字数限制、个性化记忆。
4. **面板控制是独立菜单**：字号、翻转、单/双面板、4 种文本模式，不是简单“显示/隐藏原文”。
5. **演讲模式是独立产品形态**：主持人 + 多语言观众 + 自己设备观看/收听，不能只做一个模式 chip。

## 建议下一批顺序

1. 面板 `...` 菜单：字号、翻转、单/双面板、4 种文本模式。
2. TTS 播报面板：开始/停止、音色、音量。
3. AI 助手完整弹窗：知识库、关键词标签页、字数限制、AI 学习、个性化。
4. 双面板 + 自动语言检测（LID）。
5. 6 步首次启动教程。
6. 演讲模式 / 二维码 / 局域网观众。
